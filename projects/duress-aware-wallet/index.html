Duress-Aware Wallet Security Standard

A feature layer for self-custody that survives coercion — without pretending a gunman can’t open your phone.

Self-custodial wallets give users key control but almost none of the operational brakes people expect from banks. This proposal defines an adoptable feature layer built around a second password that opens a decoy vault, geofenced secondary authentication, time-locks and multi-sig on large transfers, optional app masking, and an optional panic-drain path — plus a threat-model matrix of what each control covers, partially covers, or leaves as a gap.
